# Aim Lab

A shooting range: targets, shooting, reloading and an obstacle course.

Тренировочный тир: мишени, стрельба, перезарядка и полоса препятствий.

Official AIVERSE project template (engine folder `templates/fps_training`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create fps-training ~/AiverseProjects/MyGame
```
