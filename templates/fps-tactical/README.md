# Breach Protocol

Tactical rounds: buy weapons, plant and defuse the bomb.

Тактические раунды: покупка оружия, установка и разминирование бомбы.

Official AIVERSE project template (engine folder `templates/fps_tactical`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create fps-tactical ~/AiverseProjects/MyGame
```
