# Hold the Line

In the style of Company of Heroes: squads and capture points.

Как Company of Heroes: отряды и точки.

Official AIVERSE project template (engine folder `templates/holdtheline`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create holdtheline ~/AiverseProjects/MyGame
```
