# Green Hills

2D sprites on 3D terrain, in the style of Knights and Merchants.

2D-спрайты на 3D-рельефе (K&M).

Official AIVERSE project template (engine folder `templates/km2d`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create km2d ~/AiverseProjects/MyGame
```

## Maps

- Green Hills (1v1)
