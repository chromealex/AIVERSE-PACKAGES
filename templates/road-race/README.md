# Road Circuit

A race on a spline road circuit with four trucks whose wheels roll and steer.

Гонка по кольцу из сплайновой дороги: четыре грузовика, колёса катятся и поворачивают.

Official AIVERSE project template (engine folder `templates/road_race`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create road-race ~/AiverseProjects/MyGame
```
