# Starfall Sectors

In the style of StarCraft: three races that build in different ways.

Как StarCraft: три расы, разные стройки.

Official AIVERSE project template (engine folder `templates/starfall`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create starfall ~/AiverseProjects/MyGame
```
