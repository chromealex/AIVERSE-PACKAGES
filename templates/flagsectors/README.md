# Flag Sectors

In the style of Z: sectors with flags and factories.

Как Z: сектора с флагами и фабриками.

Official AIVERSE project template (engine folder `templates/flagsectors`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create flagsectors ~/AiverseProjects/MyGame
```
