# Iron Front

In the style of Red Alert: MCV, ore and a sidebar.

Как Red Alert: MCV, руда, сайдбар.

Official AIVERSE project template (engine folder `templates/ironfront`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create ironfront ~/AiverseProjects/MyGame
```

## Maps

- Ore Valley (1v1)
