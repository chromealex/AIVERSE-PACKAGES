# Border Rush

In the style of State.io: troops leave the bases on their own and capture cells.

Как State.io: войска сами захватывают клетки.

Official AIVERSE project template (engine folder `templates/borderrush`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create borderrush ~/AiverseProjects/MyGame
```
