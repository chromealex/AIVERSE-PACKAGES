# Iron and Gold: Scripted

Iron and Gold with Lua: a war chest, veterans, a scripted chain heal and a custom defeat condition.

Iron and Gold на Lua: казна, ветераны, цепное лечение скриптом и своё условие поражения.

Official AIVERSE project template (engine folder `templates/scripted`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create scripted ~/AiverseProjects/MyGame
```
