# Perk Arena

A hero arena with in-match progression: experience orbs, level-up perk offers, summons and a battle deck.

Арена героя с прокачкой в матче: шары опыта, выбор перков при повышении уровня, призывы и боевая колода.

Official AIVERSE project template (engine folder `templates/perk_arena`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create perk-arena ~/AiverseProjects/MyGame
```
