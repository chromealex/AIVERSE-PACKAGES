# Scrapyard Arena

A 1 vs 1 top-down hero arena: twin-stick control, virtual joystick and buttons, follow camera.

Арена героев с видом сверху 1 на 1: управление двумя стиками, виртуальный джойстик и кнопки, камера следования.

Official AIVERSE project template (engine folder `templates/topdown_arena`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create topdown-arena ~/AiverseProjects/MyGame
```
