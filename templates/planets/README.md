# Planets

A planet and a moon, orbits and flights between them. A second map is a big planet with flow fields.

Планета и луна, орбиты, перелёты. Вторая карта — большая планета с потоковыми полями.

Official AIVERSE project template (engine folder `templates/planets`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create planets ~/AiverseProjects/MyGame
```

## Maps

- Two Worlds (1v1)
- Big Planet (1v1, flow fields)
