# Clan Lands

In the style of Northgard: capture regions and pay for them with food.

Как Northgard: захват регионов за еду.

Official AIVERSE project template (engine folder `templates/clanlands`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create clanlands ~/AiverseProjects/MyGame
```

- Fjords (1v1)
