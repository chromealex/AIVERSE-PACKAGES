# Iron and Gold

Classic base building in the style of Warcraft and Red Alert: base, army, towers.

Классика Warcraft/RA: база, армия, башни.

Official AIVERSE project template (engine folder `templates/skirmish`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create skirmish ~/AiverseProjects/MyGame
```

## Maps

- River Valley (1v1)
- FX Showcase
- Tornado Valley (1v1, PHYSIS)
- Firestorm Valley (1v1, PHYSIS)
