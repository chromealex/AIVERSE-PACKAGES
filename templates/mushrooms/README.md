# Mushroom Clash

In the style of Mushroom Wars: garrisons and roads.

Как Mushroom Wars: гарнизоны и дороги.

Official AIVERSE project template (engine folder `templates/mushrooms`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create mushrooms ~/AiverseProjects/MyGame
```
