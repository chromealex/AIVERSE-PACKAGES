# Spell Bunkers

Spore Lanes with a spell book, in the style of Bunker Wars.

Spore Lanes + книга заклинаний (Bunker Wars).

Official AIVERSE project template (engine folder `templates/spellbunkers`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create spellbunkers ~/AiverseProjects/MyGame
```

## Maps

- Rune Field (1v1)
