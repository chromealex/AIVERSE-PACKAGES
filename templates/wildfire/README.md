# Wildfire

Grid fields: forest fires and spreading creep.

Поля на сетке: лесные пожары и расползающаяся слизь.

Official AIVERSE project template (engine folder `templates/wildfire`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create wildfire ~/AiverseProjects/MyGame
```
