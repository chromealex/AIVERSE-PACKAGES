# Extraction Raid

Extraction raid: containers, raid inventory, objectives, extraction points and receipts. Two maps: PvE and PvP with two raiders.

Рейд с эвакуацией: контейнеры, инвентарь рейда, задачи, точки эвакуации и итог рейда. Две карты: PvE и PvP на двоих.

Official AIVERSE project template (engine folder `templates/extraction`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create extraction ~/AiverseProjects/MyGame
```

## Maps

- Salvage Run (PvE)
- Crossfire (PvP, 2 raiders)
