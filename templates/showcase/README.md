# Model Showcase

Iron and Gold with 3D models and animation.

Iron and Gold с 3D-моделями и анимацией.

Official AIVERSE project template (engine folder `templates/showcase`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create showcase ~/AiverseProjects/MyGame
```
