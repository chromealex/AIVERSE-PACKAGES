# Last Survivor

A large map for 100 players: streamed environment, drop from a plane, a phased zone, a red zone and airdrops.

Большая карта, 100 мест, потоковая загрузка окружения, высадка с самолёта, зона по фазам, красная зона и аирдропы.

Official AIVERSE project template (engine folder `templates/fps_survival`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create fps-survival ~/AiverseProjects/MyGame
```
