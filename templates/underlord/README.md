# Underlord

In the style of Dungeon Keeper: digging, rooms and monsters.

Как Dungeon Keeper: копать, комнаты, монстры.

Official AIVERSE project template (engine folder `templates/underlord`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create underlord ~/AiverseProjects/MyGame
```

- Two Keeps (1v1)
