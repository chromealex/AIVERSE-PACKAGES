# Four Ages

In the style of Age of Empires II: four resources and ages.

Как Age of Empires II: 4 ресурса и эпохи.

Official AIVERSE project template (engine folder `templates/fourages`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create fourages ~/AiverseProjects/MyGame
```

- Highland (1v1)
