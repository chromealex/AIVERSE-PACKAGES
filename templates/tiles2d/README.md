# Crystal Dunes

2D tiles in the style of Dune II and Red Alert.

2D-тайлы как Dune II / Red Alert.

Official AIVERSE project template (engine folder `templates/tiles2d`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create tiles2d ~/AiverseProjects/MyGame
```

## Maps

- Crystal Dunes (1v1)
