# Hearth and Haul

In the style of Knights and Merchants: goods carried along roads.

Как Knights and Merchants: товары и дороги.

Official AIVERSE project template (engine folder `templates/hearthhaul`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create hearthhaul ~/AiverseProjects/MyGame
```
