# Lane Clash

A lane battler: spawners and waves.

Лайн-баттлер: спавнеры и волны.

Official AIVERSE project template (engine folder `templates/laneclash`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create laneclash ~/AiverseProjects/MyGame
```

- Long Lane (1v1)
