# Frost Crown

In the style of Warcraft III: heroes, creeps and terrain.

Как Warcraft III: герои, крипы, рельеф.

Official AIVERSE project template (engine folder `templates/frostcrown`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create frostcrown ~/AiverseProjects/MyGame
```
