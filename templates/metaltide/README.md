# Metal Tide

In the style of Total Annihilation: flow economy, radar, reclaim, aircraft and nukes.

Как Total Annihilation: потоки ресурсов, радар, переработка, авиация и ядерные ракеты.

Official AIVERSE project template (engine folder `templates/metaltide`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create metaltide ~/AiverseProjects/MyGame
```
