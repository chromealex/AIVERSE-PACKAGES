# Crossfire Arena

A 5 vs 5 team arena: cover, bots and a network match.

Командная арена 5 на 5: укрытия, боты и сетевой матч.

Official AIVERSE project template (engine folder `templates/fps_arena`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create fps-arena ~/AiverseProjects/MyGame
```
