# Last Colony

In the style of They Are Billions: survive the waves. A second map has huge hordes on flow fields.

Как They Are Billions: выжить в волнах. На второй карте огромные орды на потоковых полях.

Official AIVERSE project template (engine folder `templates/lastcolony`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create lastcolony ~/AiverseProjects/MyGame
```

## Maps

- Last Valley (survival)
- Horde Plain (big hordes, flow fields)
