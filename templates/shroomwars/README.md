# Shroom Wars

In the style of Mushroom Wars 2: levels, forges, morale and heroes.

Mushroom Wars 2: уровни, кузницы, мораль, герои.

Official AIVERSE project template (engine folder `templates/shroomwars`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create shroomwars ~/AiverseProjects/MyGame
```
