# Oval Sprint

A race on an oval: starting grid, countdown, three laps against three bots, positions, wrong-way detection and returning to the track.

Гонка на овале: сетка старта, отсчёт, три круга против трёх ботов, позиции, езда не в ту сторону и возврат на трассу.

Official AIVERSE project template (engine folder `templates/racing`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create racing ~/AiverseProjects/MyGame
```
