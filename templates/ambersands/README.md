# Amber Sands

In the style of Dune II: spice harvesting, windtraps and a sandworm in the dunes.

Как Dune II: спайс, ветряки, червь в песках.

Official AIVERSE project template (engine folder `templates/ambersands`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create ambersands ~/AiverseProjects/MyGame
```
