# Golem Pit

A top-down hero against a three-phase golem boss with adds and crawler packs: telegraphed area attacks, statuses and boss phases.

Герой с видом сверху против трёхфазного босса-голема с прислужниками и стаями ползунов: атаки по площади с предупреждением, статусы и фазы босса.

Official AIVERSE project template (engine folder `templates/boss_arena`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create boss-arena ~/AiverseProjects/MyGame
```
