# Blockworld

A block sandbox: dig, build and survive the night. Endless world, fluids, mobs, network play.

Песочница из блоков: копайте, стройте, переживите ночь. Бесконечный мир, жидкости, мобы, сетевая игра.

Official AIVERSE project template (engine folder `templates/voxel_sandbox`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create voxel-sandbox ~/AiverseProjects/MyGame
```
