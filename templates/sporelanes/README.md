# Spore Lanes

In the style of Mushroom Wars 2: columns along lanes.

Как Mushroom Wars 2: колонны по линиям.

Official AIVERSE project template (engine folder `templates/sporelanes`).

## Start a project from it

In AIVERSE Studio: the start screen lists the official templates; pick it and press **Create**.
From a shell:

```sh
python3 tools/pkg/aiverse_pkg.py create sporelanes ~/AiverseProjects/MyGame
```

- Spore Field (1v1)
